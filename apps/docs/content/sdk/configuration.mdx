# Configuration

Configure the Simplist client with various options to suit your application's needs.

## Client Options

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient({
  apiKey: 'your_api_key',
  baseUrl: 'https://api.simplist.blog',
  path: 'blog',
  timeout: 10000,
  retries: 3,
  retryDelay: 1000,
});
```

### Available Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `apiKey` | string | - | API key (required if not set via env) |
| `baseUrl` | string | `https://api.simplist.blog` | API base URL |
| `path` | string | - | Global path for SEO URLs |
| `timeout` | number | `10000` | Request timeout (ms) |
| `retries` | number | `3` | Number of retry attempts |
| `retryDelay` | number | `1000` | Delay between retries (ms) |

## API Key

### From Options

```typescript
const client = new SimplistClient({
  apiKey: 'your_api_key',
});
```

### From Environment Variable

```bash
# .env
SIMPLIST_API_KEY=your_api_key
```

```typescript
// Auto-detects from environment
const client = new SimplistClient();
```

<Callout type="info">
The SDK automatically detects `SIMPLIST_API_KEY` from `process.env` in Node.js environments.
</Callout>

### Key Permissions

**API Keys with Read Permission** - Server-side only:
```typescript
const client = new SimplistClient({
  apiKey: 'your_api_key', // API key with read permission
});
```

**API Keys with Analytics Permission** - Safe for client-side:
```typescript
const client = new SimplistClient({
  apiKey: 'your_api_key', // API key with analytics permission
});
```

<Callout type="warn">
Never expose API keys with read permission in client-side code. Use API keys with analytics permission for browser environments.
</Callout>

## Base URL

Override the API base URL (useful for testing):

```typescript
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
  baseUrl: 'https://api-staging.simplist.blog',
});
```

Default: `https://api.simplist.blog`

## Global Path

Set a global path for all SEO URLs:

```typescript
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
  path: 'blog', // URLs will be: /blog/{slug}
});

// Generate sitemap
const sitemap = await client.seo.getSitemap('https://myblog.com', 'xml');
// Articles will be: https://myblog.com/blog/article-slug
```

Common paths:
- `blog` → `/blog/{slug}`
- `articles` → `/articles/{slug}`
- `posts` → `/posts/{slug}`
- Custom: `content/posts` → `/content/posts/{slug}`

## Timeout

Configure request timeout in milliseconds:

```typescript
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
  timeout: 5000, // 5 seconds
});
```

Default: `10000` (10 seconds)

<Callout type="info">
Increase timeout for slow connections or decrease for faster failure detection.
</Callout>

## Retries

Configure automatic retry behavior:

```typescript
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
  retries: 5, // Retry up to 5 times
  retryDelay: 2000, // Wait 2 seconds between retries
});
```

### Retry Logic

The SDK automatically retries failed requests with exponential backoff:
- Network errors
- 5xx server errors
- Rate limit errors (429)

Requests that won't retry:
- 4xx client errors (except 429)
- Invalid API key (401)
- Not found (404)

Default: 3 retries with 1 second delay

## Validation

The SDK validates configuration on initialization:

```typescript
// ❌ Error: API key is required
const client = new SimplistClient();

// ❌ Error: Invalid API key format
const client = new SimplistClient({
  apiKey: 'invalid_key',
});

// ✅ Valid
const client = new SimplistClient({
  apiKey: 'your_api_key',
});
```

## Best Practices

### 1. Use Environment Variables

```typescript
// ✅ Good
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});

// ❌ Bad - hardcoded key
const client = new SimplistClient({
  apiKey: 'hardcoded_key',
});
```

### 2. Set Global Path

```typescript
// ✅ Good - set once
const client = new SimplistClient({
  path: 'blog',
});

// ❌ Bad - repeat in every SEO call
await client.seo.getSitemap(baseUrl, 'xml', 'blog/{slug}');
```

### 3. Configure Retries Appropriately

```typescript
// ✅ Good - reasonable retries
retries: 3

// ❌ Bad - too many retries (slow failure)
retries: 10

// ❌ Bad - no retries (fails on transient errors)
retries: 0
```

### 4. Singleton Pattern

```typescript
// lib/simplist.ts
let client: SimplistClient | null = null;

export function getSimplistClient() {
  if (!client) {
    client = new SimplistClient({
      apiKey: process.env.SIMPLIST_API_KEY,
    });
  }
  return client;
}
```
