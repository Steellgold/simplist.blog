# Simplist SDK

The official TypeScript/JavaScript SDK for the Simplist API. Build powerful blog applications with type-safe, promise-based methods.

<Callout type="info">
The SDK provides a clean, intuitive interface to the Simplist API with built-in TypeScript support, automatic retries, and error handling.
</Callout>

## Features

- ✅ **Full TypeScript support** with complete type definitions
- ✅ **Promise-based API** with async/await
- ✅ **Automatic retries** with configurable delays
- ✅ **Error handling** with detailed error messages
- ✅ **Environment variable support** for API keys
- ✅ **Zero dependencies** - lightweight and fast
- ✅ **ESM and CommonJS** support
- ✅ **Node.js 18+** and modern browsers

## Quick Start

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

// Initialize client
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});

// Fetch articles
const articles = await client.articles.list({
  published: true,
  limit: 10,
});

// Get single article
const article = await client.articles.get('my-article-slug');

// Track analytics
await client.analytics.track({
  articleSlug: 'my-article-slug',
  visitorId: 'visitor_123',
  sessionId: 'session_456',
  pageUrl: 'https://myblog.com/articles/my-article-slug',
});

// Get project stats
const project = await client.project.get();
console.log(`Total articles: ${project.stats.totalArticles}`);
```

## Client Options

```typescript
const client = new SimplistClient({
  // API key (required, or set SIMPLIST_API_KEY env var)
  apiKey: 'your_api_key',

  // Base URL (optional, defaults to https://api.simplist.blog)
  baseUrl: 'https://api.simplist.blog',

  // Global path for SEO URLs (optional, e.g., 'blog', 'articles')
  path: 'blog',

  // Request timeout in ms (optional, default: 10000)
  timeout: 10000,

  // Number of retries (optional, default: 3)
  retries: 3,

  // Delay between retries in ms (optional, default: 1000)
  retryDelay: 1000,
});
```

## Environment Variables

The SDK automatically detects the `SIMPLIST_API_KEY` environment variable:

```typescript
// .env

```

## Error Handling

The SDK throws `SimplistApiError` for API errors:

```typescript
import { SimplistClient, SimplistApiError } from '@simplist.blog/sdk';

const client = new SimplistClient();

try {
  const article = await client.articles.get('non-existent-slug');
} catch (error) {
  if (error instanceof SimplistApiError) {
    console.error('API Error:', error.message);
    console.error('Status:', error.status);
    console.error('Code:', error.code);
  } else {
    console.error('Unexpected error:', error);
  }
}
```

## Next.js Integration

Perfect for Next.js applications:

```typescript
// app/articles/[slug]/page.tsx
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient();

export async function generateStaticParams() {
  const { data: articles } = await client.articles.list();

  return articles.map((article) => ({
    slug: article.slug,
  }));
}

export default async function ArticlePage({
  params,
}: {
  params: { slug: string };
}) {
  const { data: article } = await client.articles.get(params.slug);

  return (
    <article>
      <h1>{article.title}</h1>
      <div dangerouslySetInnerHTML={{ __html: article.content }} />
    </article>
  );
}
```

## React Integration

Use in React components:

```typescript
import { SimplistClient } from '@simplist.blog/sdk';
import { useEffect, useState } from 'react';

const client = new SimplistClient();

function ArticleList() {
  const [articles, setArticles] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function fetchArticles() {
      try {
        const { data } = await client.articles.list({ limit: 10 });
        setArticles(data);
      } catch (error) {
        console.error('Failed to fetch articles:', error);
      } finally {
        setLoading(false);
      }
    }

    fetchArticles();
  }, []);

  if (loading) return <div>Loading...</div>;

  return (
    <div>
      {articles.map((article) => (
        <div key={article.id}>
          <h2>{article.title}</h2>
          <p>{article.excerpt}</p>
        </div>
      ))}
    </div>
  );
}
```

## Browser Usage

The SDK works in modern browsers:

```html
<script type="module">
  import { SimplistClient } from 'https://cdn.skypack.dev/@simplist.blog/sdk';

  const client = new SimplistClient({
    apiKey: 'your_api_key', // Use API key with analytics permission in browser
  });

  const { data: articles } = await client.articles.list();
  console.log(articles);
</script>
```

<Callout type="warn">
Never expose API keys with read permission in client-side code. Use API keys with analytics permission for browser environments.
</Callout>

## API Compatibility

The SDK matches the Simplist API v1. All endpoints and features are supported:

- Articles: list, get, search
- Projects: get info and stats
- Analytics: track, update, stats
- SEO: metadata, sitemaps, RSS, structured data
