## Filtering by Tags

### Tags Filter (OR Logic)

Get articles with at least one of the specified tags:

<CodeBlock language="tsx">
{`
  // Articles about JavaScript OR TypeScript
  const { data } = await client.articles.list({
    tags: ['JavaScript', 'TypeScript']
  })

  // Articles with web development tags
  const { data: webArticles } = await client.articles.list({
    tags: ['JavaScript', 'HTML', 'CSS'],
    published: true
  })
`}
</CodeBlock>

### Tags All Filter (AND Logic)

Get articles that have all specified tags:

<CodeBlock language="tsx">
{`
  // Articles that are BOTH tutorials AND about JavaScript
  const { data: jsTutorials } = await client.articles.list({
    tagsAll: ['Tutorial', 'JavaScript']
  })

  // Complex requirements: beginner tutorials about web development
  const { data: beginnerWeb } = await client.articles.list({
    tagsAll: ['Tutorial', 'Beginner', 'Web Development']
  })
`}
</CodeBlock>

### Exclude Tags

Get articles that don't have specific tags:

<CodeBlock language="tsx">
{`
  // Articles without Advanced or Deprecated tags
  const { data: beginnerArticles } = await client.articles.list({
    excludeTags: ['Advanced', 'Deprecated']
  })

  // Published articles, excluding work in progress
  const { data: finishedArticles } = await client.articles.list({
    published: true,
    excludeTags: ['WIP', 'Draft']
  })
`}
</CodeBlock>

### Combining Tag Filters

Combine multiple tag filters for complex queries:

<CodeBlock language="tsx">
{`
  const { data: beginnerWebTutorials } = await client.articles.list({
    tags: ['JavaScript', 'TypeScript'],      // OR: at least one of these
    tagsAll: ['Tutorial'],                   // AND: must have this tag
    excludeTags: ['Advanced'],               // NOT: must not have this tag
    published: true
  })
`}
</CodeBlock>

## Field Selection

Control which fields are included in the response to optimize payload size and performance.

### Excluding Heavy Fields

By default, articles include all fields including the full `content`. Use `select` to exclude heavy fields:

<CodeBlock language="tsx">
{`
  // Exclude content for list views (lighter response)
  const { data: articles } = await client.articles.list({
    select: {
      content: false, // Exclude content
      variants: false // Exclude translations
    },
    published: true,
    limit: 20
  })

  // Perfect for blog listing pages where you only need title and excerpt
  articles.forEach(article => {
    console.log(article.title) // ✓ Available
    console.log(article.excerpt) // ✓ Available
    console.log(article.content) // undefined
  })
`}

</CodeBlock>

### Including Only Specific Fields

Set fields to `true` to explicitly include them (especially useful with tag metadata):

<CodeBlock language="tsx">
{`
  // Get articles with tag colors and icons
  const { data: articlesWithTags } = await client.articles.list({
    select: {
      tagColor: true, // Include tag hex colors
      tagIcon: true   // Include tag icons
    }
  })

  articlesWithTags[0].tags.forEach(tag => {
    console.log(\`\${tag.name}: \${tag.color} (\${tag.icon})\`)
  })
  // Output: "React: #61DAFB (react)"
`}

</CodeBlock>

### Default Behavior

**Without `select`:** All fields are included (backwards compatible)  
**With `select`:** Only specified fields are included (defaults to `false` for unspecified fields)

<CodeBlock language="tsx">
{`
  // No select = all fields included
  const { data: full } = await client.articles.list()
  console.log(full[0].content) // ✓ Available (includes everything)

  // With select = only specified fields
  const { data: minimal } = await client.articles.list({
    select: {
      title: true,
      excerpt: true
      // content and other fields are excluded
    }
  })

  console.log(minimal[0].content) // undefined
`}

</CodeBlock>

              <a href={\`/blog/\${article.slug}\`}>Read more</a>
            </article>
          ))}
        </div>

        <Pagination
          currentPage={meta.page}
          totalPages={meta.totalPages}
        />
      </div>
    )
}`},

      filename: "app/blog/[slug]/page.tsx",

  import { notFound } from "next/navigation";

  export default async function ArticlePage({
    params
  }: {
    params: Promise<{ slug: string }>
  }) {
    const { slug } = await params;
    const client = new SimplistClient()

    try {
      const { data: article } = await client.articles.get(params.slug)

      return (
        <article>
          <header>
            <h1>{article.title}</h1>
            <p>By {article.author.name}</p>
            <time>{new Date(article.publishedAt).toLocaleDateString()}</time>
            <span>{article.readTimeMinutes} min read</span>
          </header>

          <div dangerouslySetInnerHTML={{ __html: article.content }} />

          <footer>
            <p>{article.viewCount} views</p>
          </footer>
        </article>
      )
    } catch {
      notFound()
    }
  }`},
