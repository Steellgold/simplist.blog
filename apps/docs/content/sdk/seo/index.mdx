# SEO Resource

The SEO resource provides methods to generate SEO metadata, sitemaps, RSS feeds, and structured data.

## Available Methods

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient({ path: 'blog' });

// Get article with SEO metadata
const article = await client.seo.getArticle('my-slug', 'https://myblog.com');

// Generate XML sitemap
const xml = await client.seo.getSitemap('https://myblog.com', 'xml');

// Generate JSON sitemap
const json = await client.seo.getSitemap('https://myblog.com', 'json');

// Generate RSS feed
const rss = await client.seo.getRssFeed('https://myblog.com', 50);

// Get structured data for all articles
const structured = await client.seo.getStructuredData('https://myblog.com');
```

<Callout type="info">
Set a global `path` when creating the client to avoid repeating it in every SEO call.
</Callout>

## getArticle()

Fetch article with complete SEO metadata.

```typescript
async getArticle(
  slug: string,
  baseUrl: string,
  lang?: string
): Promise<ArticleWithSeo>
```

### Parameters

- `slug` - Article slug
- `baseUrl` - Base URL for your blog (e.g., `https://myblog.com`)
- `lang` - Optional language code for variant SEO

### Example

<Tabs items={['TypeScript', 'JavaScript']}>
<Tab value="TypeScript">
```typescript
const article = await client.seo.getArticle(
  'getting-started',
  'https://myblog.com'
);

// Use SEO metadata
const { seo } = article;

console.log('Title:', seo.title);
console.log('Description:', seo.description);
console.log('Canonical:', seo.canonical);
console.log('OG Image:', seo.openGraph.image);
```
</Tab>
<Tab value="JavaScript">

</Tab>

### Next.js Metadata

```typescript
// app/articles/[slug]/page.tsx
import { SimplistClient } from '@simplist.blog/sdk';
import { Metadata } from 'next';

const client = new SimplistClient();

export async function generateMetadata({
  params,
}: {
  params: { slug: string };
}): Promise<Metadata> {
  const article = await client.seo.getArticle(
    params.slug,
    process.env.NEXT_PUBLIC_BASE_URL!
  );

  const { seo } = article;

  return {
    title: seo.title,
    description: seo.description,
    openGraph: {
      title: seo.openGraph.title,
      description: seo.openGraph.description,
      images: [seo.openGraph.image],
      type: 'article',
    },
    twitter: {
      card: 'summary_large_image',
      title: seo.twitter.title,
      description: seo.twitter.description,
      images: [seo.twitter.image],
    },
  };
}
```

## getSitemap()

Generate sitemap in XML or JSON format.

```typescript
async getSitemap(
  baseUrl: string,
  format: 'xml' | 'json' = 'xml',
  customPath?: string
): Promise<string | Sitemap>
```

### Parameters

- `baseUrl` - Base URL for your blog
- `format` - `'xml'` or `'json'` (default: `'xml'`)
- `customPath` - Optional custom path pattern (uses global `path` if not provided)

### XML Sitemap Example

```typescript
const xml = await client.seo.getSitemap('https://myblog.com', 'xml');

// Returns XML string
console.log(xml);
```

### JSON Sitemap Example

```typescript
const sitemap = await client.seo.getSitemap('https://myblog.com', 'json');

// Returns typed object
sitemap.entries.forEach(entry => {
  console.log(`${entry.url} - ${entry.lastModified}`);
});
```

### Next.js Sitemap Route

```typescript
// app/sitemap.xml/route.ts
import { SimplistClient } from '@simplist.blog/sdk';
import { NextResponse } from 'next/server';

const client = new SimplistClient({ path: 'blog' });

export async function GET() {
  const xml = await client.seo.getSitemap(
    process.env.NEXT_PUBLIC_BASE_URL!,
    'xml'
  );

  return new NextResponse(xml, {
    headers: {
      'Content-Type': 'application/xml',
      'Cache-Control': 'public, max-age=3600',
    },
  });
}
```

## getRssFeed()

Generate RSS 2.0 feed.

```typescript
async getRssFeed(
  baseUrl: string,
  limit: number = 20,
  lang?: string,
  customPath?: string
): Promise<string>
```

### Example

```typescript
const rss = await client.seo.getRssFeed('https://myblog.com', 50);

// Returns RSS XML string
console.log(rss);
```

### Next.js RSS Route

```typescript
// app/rss.xml/route.ts
import { SimplistClient } from '@simplist.blog/sdk';
import { NextResponse } from 'next/server';

const client = new SimplistClient({ path: 'blog' });

export async function GET() {
  const rss = await client.seo.getRssFeed(
    process.env.NEXT_PUBLIC_BASE_URL!,
    50
  );

  return new NextResponse(rss, {
    headers: {
      'Content-Type': 'application/rss+xml; charset=utf-8',
      'Cache-Control': 'public, max-age=3600',
    },
  });
}
```

## getStructuredData()

Get Schema.org structured data for all articles.

```typescript
async getStructuredData(
  baseUrl?: string,
  limit: number = 200,
  offset: number = 0
): Promise<StructuredDataResponse>
```

### Example

```typescript
const data = await client.seo.getStructuredData('https://myblog.com', 100);

console.log(`Project: ${data.project.name}`);
console.log(`Articles: ${data.articles.length}`);

data.articles.forEach(article => {
  console.log(`- ${article.slug}`);
  console.log(JSON.stringify(article.structuredData, null, 2));
});
```

### Response

```typescript
{
  project: {
    name: string;
    slug: string;
  };
  articles: Array<{
    slug: string;
    structuredData: {
      '@context': string;
      '@type': string;
      headline: string;
      description: string;
      image: string;
      datePublished: string;
      dateModified: string;
      author: {
        '@type': string;
        name: string;
      };
    };
  }>;
  generatedAt: string;
}
```

## Custom Path Patterns

Configure custom URL structures:

```typescript
// Set global path in client
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
  path: 'blog', // All SEO URLs will use /blog/{slug}
});

// Override per call
const sitemap = await client.seo.getSitemap(
  'https://myblog.com',
  'xml',
  'articles/{slug}' // Use /articles/{slug} instead
);
```

## Caching

All SEO endpoints are cached for 5 minutes server-side. Consider caching responses client-side:

```typescript
const cache = new Map();

async function getCachedSitemap() {
  if (cache.has('sitemap')) {
    return cache.get('sitemap');
  }

  const sitemap = await client.seo.getSitemap('https://myblog.com', 'xml');
  cache.set('sitemap', sitemap);

  return sitemap;
}
```

## Complete Example

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
  path: 'blog',
});

async function setupSEO() {
  const baseUrl = 'https://myblog.com';

  // 1. Get article SEO
  const article = await client.seo.getArticle('my-article', baseUrl);
  console.log('Article SEO:', article.seo.title);

  // 2. Generate sitemap
  const sitemap = await client.seo.getSitemap(baseUrl, 'xml');
  console.log('Sitemap generated');

  // 3. Generate RSS feed
  const rss = await client.seo.getRssFeed(baseUrl, 50);
  console.log('RSS feed generated');

  // 4. Get structured data
  const structured = await client.seo.getStructuredData(baseUrl);
  console.log(`Structured data for ${structured.articles.length} articles`);
}

setupSEO();
```
