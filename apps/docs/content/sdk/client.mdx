# SimplistClient

The main client for interacting with the Simplist API.

## Constructor

<MethodSignature
  name="SimplistClient"
  parameters={[
    { name: "options", type: "SimplistClientOptions", optional: true }
  ]}
  returnType="SimplistClient"
/>

### Configuration Options

<TypeTable
  title="SimplistClientOptions"
  properties={[
    { name: "apiKey", type: "string", description: "API key for authentication (auto-detected from SIMPLIST_API_KEY env var)", required: false },
    { name: "baseUrl", type: "string", description: "Base URL for the API", defaultValue: "https://api.simplist.blog" },
    { name: "apiVersion", type: "string", description: "API version to use (e.g., '1', '2'). Automatically adds /v{version}/ prefix to all requests", defaultValue: "1" },
    { name: "path", type: "string", description: "Global path for article URLs (e.g., 'blog', 'articles')" },
    { name: "timeout", type: "number", description: "Request timeout in milliseconds", defaultValue: "10000" },
    { name: "retries", type: "number", description: "Number of retry attempts for failed requests", defaultValue: "3" },
    { name: "retryDelay", type: "number", description: "Delay between retries in milliseconds", defaultValue: "1000" }
  ]}
/>

### Example

<CodeBlock language="typescript">
{`
  import { SimplistClient } from '@simplist.blog/sdk'

  const client = new SimplistClient({
    apiKey: process.env.SIMPLIST_API_KEY,
    apiVersion: '1',  // Use API v1 (default)
    path: 'blog',     // Articles will be at yoursite.com/blog/article-slug
    timeout: 5000,
    retries: 2
  })

  // Or for future v2 API
  const v2Client = new SimplistClient({
    apiKey: process.env.SIMPLIST_API_KEY,
    apiVersion: '2'  // Use API v2
  })
`}
</CodeBlock>

The SimplistClient exposes 4 resource modules:

Access the Articles API for fetching and managing articles.

## Complete Example

<CodeBlock language="typescript">
{`
  import { SimplistClient } from '@simplist.blog/sdk'

  // Initialize client
  const client = new SimplistClient({
    apiKey: process.env.SIMPLIST_API_KEY,
    path: 'blog'
  })

  // Test connection
  try {
    const health = await client.ping()
    console.log('✓ API connection successful')

    // Fetch articles
    const { data: articles } = await client.articles.list({ limit: 5 })
    console.log(\`✓ Found \${articles.length} articles\`)

    // Get project stats
    const { project, stats } = await client.project.get()
    console.log(\`✓ Project: \${project.name}\`)
    console.log(\`✓ Total views: \${stats.totalViews}\`)

  } catch (error) {
    console.error('✗ Error:', error.message)
  }
`}
</CodeBlock>

## Error Handling

All methods can throw `SimplistApiError` for API errors:

<CodeBlock language="typescript">
{`
  import { SimplistClient, SimplistApiError } from '@simplist.blog/sdk'

  // Uses SIMPLIST_API_KEY from environment variables
  const client = new SimplistClient()

  try {
    await client.ping()
  } catch (error) {
    if (error instanceof SimplistApiError) {
      console.error(\`API Error [\${error.statusCode}]:\`, error.message)
      console.error(\`Details: \${error.details}\`)
    } else {
      console.error(\`Network Error: \${error}\`)
    }
  }
`}
</CodeBlock>

See [Error Handling](/error-handling) for more information.
