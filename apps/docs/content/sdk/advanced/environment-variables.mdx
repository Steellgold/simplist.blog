# Environment Variables

Secure way to manage API keys and configuration.

## Setup

Create a `.env` file in your project root:

```bash title=".env"
SIMPLIST_API_KEY=your_api_key
```

<Callout type="warn">
**Never commit `.env` files to version control!** Add `.env` to your `.gitignore`.
</Callout>

## Auto-Detection

The SDK automatically detects `SIMPLIST_API_KEY`:

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

// No apiKey needed - auto-detects from env
const client = new SimplistClient();
```

## Framework-Specific

### Next.js

```bash title=".env.local"
# Server-side (API key with read permission)
SIMPLIST_API_KEY=your_api_key

# Client-side (API key with analytics permission)
NEXT_PUBLIC_SIMPLIST_API_KEY=your_api_key
```

```typescript
// Server Component
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});

// Client Component
const client = new SimplistClient({
  apiKey: process.env.NEXT_PUBLIC_SIMPLIST_API_KEY,
});
```

### Vite

```bash title=".env"
VITE_SIMPLIST_API_KEY=your_api_key
```

```typescript
const client = new SimplistClient({
  apiKey: import.meta.env.VITE_SIMPLIST_API_KEY,
});
```

### Node.js

```typescript
import 'dotenv/config';

const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});
```

## Validation

```typescript
if (!process.env.SIMPLIST_API_KEY) {
  throw new Error('SIMPLIST_API_KEY is required');
}

const client = new SimplistClient();
```

## Best Practices

### 1. Use Read Permission Keys Server-Side

```typescript
// ✅ Good - server-side with read permission
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});
```

### 2. Use Analytics Permission Keys Client-Side

```typescript
// ✅ Good - client-side with analytics permission
const client = new SimplistClient({
  apiKey: process.env.NEXT_PUBLIC_SIMPLIST_API_KEY,
});
```

### 3. Never Hardcode Keys

```typescript
// ❌ Bad - hardcoded key
const client = new SimplistClient({
  apiKey: 'hardcoded_key',
});

// ✅ Good - from environment
const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});
```

### 4. Add to .gitignore

```bash title=".gitignore"
.env
.env.local
.env.*.local
```

### 5. Use .env.example

```bash title=".env.example"
SIMPLIST_API_KEY=your_api_key
NEXT_PUBLIC_SIMPLIST_API_KEY=your_api_key
```

Commit `.env.example` to show required variables without exposing secrets.

## Deployment

### Vercel

Add environment variables in project settings:
- `SIMPLIST_API_KEY` for server-side
- `NEXT_PUBLIC_SIMPLIST_API_KEY` for client-side

### Netlify

```bash
# netlify.toml
[build.environment]
  SIMPLIST_API_KEY = "your_api_key"
```

### Railway / Render

Add environment variables in dashboard.

<Callout type="info">
Most platforms support `.env` files for local development and dashboard configuration for production.
</Callout>
