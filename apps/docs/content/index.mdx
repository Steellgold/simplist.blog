# Getting Started

Simplist is a headless CMS for blogs. It provides an SDK and REST API to manage articles, track analytics, and handle SEO.

## Installation & Setup

<Steps>
  <Step
    title="Install the SDK"
    description="Add Simplist to your project with your preferred package manager."
  >
    <StepContent>
      <InstallationTabs
        commands={{
          npm: "npm install @simplist.blog/sdk",
          pnpm: "pnpm add @simplist.blog/sdk",
          yarn: "yarn add @simplist.blog/sdk",
          bun: "bun add @simplist.blog/sdk"
        }}
      />
    </StepContent>
  </Step>

  <Step
    title="Get your API key"
    description="Create a project and get your API key from your dashboard at simplist.blog."
  />

  <Step
    title="Configure the environment"
    description="Add your API key to your .env file. This variable will be automatically used by the SDK."
  >
    <StepContent>
      <EnvVars
        variables={[
          {
            name: "SIMPLIST_API_KEY",
            description: "Your Simplist project API key",
            required: true
          }
        ]}
      />
    </StepContent>
  </Step>

  <Step
    title="Initialize the client"
    description="Create a new instance of the SimplistClient to start fetching articles."
  >

    <StepContent>
      <CodeBlock language="typescript">
  {`
  import { SimplistClient } from '@simplist.blog/sdk'

  const client = new SimplistClient({
    apiKey: process.env.SIMPLIST_API_KEY
  })
`}
      </CodeBlock>
    </StepContent>
  </Step>
</Steps>


### Direct Configuration

Alternatively, pass the API key directly when creating the client:

<CodeBlock language="typescript" filename="client.ts">
  {`
  import { SimplistClient } from '@simplist.blog/sdk'

  const client = new SimplistClient({
    apiKey: 'prj_your_api_key'
  })
  `}
</CodeBlock>

## Basic Usage

### Fetch Latest Articles

<CodeBlock language="typescript" filename="client.ts">
  {`
  import { SimplistClient } from '@simplist.blog/sdk'

  const client = new SimplistClient({
    apiKey: process.env.SIMPLIST_API_KEY
  })

  const response = await client.articles.latest(10)

  if (response.success) {
    console.log(response.data)
  }
  `}
</CodeBlock>

### Get a Specific Article

<CodeBlock language="typescript" filename="client.ts">
  {`
  const response = await client.articles.get('article-slug')

  if (response.success) {
    const article = response.data
    console.log(article.title)
    console.log(article.content)
  }
  `}
</CodeBlock>

### List All Published Articles

<CodeBlock language="typescript" filename="client.ts">
  {`
  const response = await client.articles.published({
    page: 1,
    limit: 20
  })

  if (response.success) {
    const articles = response.data
    articles.forEach(article => {
      console.log(article.title)
    })
  }
  `}
</CodeBlock>

## Configuration Options

<CodeBlock language="typescript" filename="client.ts">
  {`
  const client = new SimplistClient({
    apiKey: 'prj_your_api_key',      // Required
    baseUrl: 'https://api.simplist.blog', // Optional, default shown
    path: 'blog',                     // Optional, URL prefix for articles
    timeout: 10000,                   // Optional, request timeout in ms
    retries: 3,                       // Optional, number of retries
    retryDelay: 1000                  // Optional, delay between retries in ms
  })
  `}
</CodeBlock>

## Response Format

All SDK methods return this format:

<CodeBlock language="typescript" filename="client.ts">
  {`
  {
    success: boolean
    data?: any          // Present if success is true
    error?: {           // Present if success is false
      message: string
      status?: number
    }
    meta?: {            // Present for list endpoints
      page: number
      limit: number
      total: number
      totalPages: number
    }
  }
  `}
</CodeBlock>
