# Introduction

Welcome to the introduction to Simplist - a modern, headless blogging platform with built-in analytics and SEO features.

## What is Simplist?

Simplist is a **multi-tenant headless blog platform** that provides:

✅ **RESTful API** - Fetch articles, track analytics, generate SEO metadata

✅ **TypeScript SDK** - Type-safe client with automatic retries

✅ **Multi-language support** - Article variants for internationalization

✅ **Privacy-first analytics** - Track engagement without compromising privacy

✅ **SEO optimized** - Automatic sitemaps, RSS feeds, structured data

✅ **Two subscription tiers** - Free STARTER and PRO plans

## Getting Started

### 1. Create Your Project

Sign up at [app.simplist.blog](https://app.simplist.blog) and create your first project.

### 2. Get Your API Key

Navigate to your project settings and create an API key with appropriate permissions:
- **Read permission** for server-side use
- **Analytics permission** for client-side use

### 3. Choose Your Approach

**Option A: Use the SDK (Recommended)**

```bash
pnpm add @simplist.blog/sdk
```

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient({
  apiKey: process.env.SIMPLIST_API_KEY,
});

const { data: articles } = await client.articles.list({ limit: 10 });
```

**Option B: Use the REST API Directly**

```bash
curl https://api.simplist.blog/v1/articles?published=true \
  -H "X-API-Key: your_api_key"
```

## Core Features

### Articles Management

Fetch and display your blog articles with full Markdown content, multi-language variants, and metadata.

```typescript
// Get published articles
const { data } = await client.articles.published({ limit: 10 });

// Get single article with variants
const { data: article } = await client.articles.get('article-slug');
```

[Learn more about Articles →](/sdk/articles)

### Privacy-First Analytics

Track page views and engagement metrics while respecting user privacy:

```typescript
await client.analytics.track({
  articleSlug: 'my-article',
  visitorId: 'visitor_123',
  pageUrl: 'https://myblog.com/articles/my-article',
});

const stats = await client.analytics.getStats({ days: 30 });
```

[Learn more about Analytics →](/sdk/analytics)

### SEO & Discovery

Automatic SEO metadata, sitemaps, RSS feeds, and structured data:

```typescript
// Get SEO metadata
const article = await client.seo.getArticle('slug', 'https://myblog.com');

// Generate XML sitemap
const sitemap = await client.seo.getSitemap('https://myblog.com', 'xml');

// Generate RSS feed
const rss = await client.seo.getRssFeed('https://myblog.com', 50);
```

[Learn more about SEO →](/sdk/seo)

## Example Projects

### Next.js Blog

```tsx
// app/page.tsx
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient();

export default async function HomePage() {
  const { data: articles } = await client.articles.published({ limit: 10 });

  return (
    <div>
      <h1>Latest Articles</h1>
      {articles.map(article => (
        <article key={article.id}>
          <h2>{article.title}</h2>
          <p>{article.excerpt}</p>
          <a href={`/articles/${article.slug}`}>Read more</a>
        </article>
      ))}
    </div>
  );
}
```

### React Hook

```tsx
import { SimplistClient } from '@simplist.blog/sdk';
import { useEffect, useState } from 'react';

const client = new SimplistClient();

function useArticles(limit = 10) {
  const [articles, setArticles] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function fetchArticles() {
      const { data } = await client.articles.list({ limit });
      setArticles(data);
      setLoading(false);
    }
    fetchArticles();
  }, [limit]);

  return { articles, loading };
}
```
