# /v1/seo/article/:slug

Retrieve an article with complete SEO metadata for use in meta tags, Open Graph, and Twitter Cards.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/seo/article/:slug"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    { name: "slug", type: "string", required: true, description: "Article slug" }
  ]}
/>

## Response

<TypeTable
  title="ArticleWithSeo"
  properties={[
    { name: "id", type: "string", required: true },
    { name: "title", type: "string", required: true },
    { name: "slug", type: "string", required: true },
    { name: "content", type: "string", required: true },
    { name: "seo", type: "SeoMetadata", required: true },
    { name: "project", type: "{ name, slug, description }", required: true }
  ]}
/>

### SeoMetadata

<TypeTable
  title="SeoMetadata"
  properties={[
    { name: "metaTitle", type: "string", required: true },
    { name: "metaDescription", type: "string", required: true },
    { name: "ogTitle", type: "string" },
    { name: "ogDescription", type: "string" },
    { name: "ogImage", type: "string" },
    { name: "twitterCard", type: "'summary' | 'summary_large_image'", required: true },
    { name: "canonicalUrl", type: "string" },
    { name: "keywords", type: "string[]" },
    { name: "structuredData", type: "object", description: "JSON-LD data" }
  ]}
/>
