# /v1/analytics/stats

Retrieve comprehensive analytics statistics for your project, including total views, top articles, and geographic data.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/analytics/stats"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    { name: "days", type: "number", required: false, description: "Number of days to include (default: 30, max: 365)" }
  ]}
/>

## Query Parameters

<TypeTable
  properties={[
    { name: "days", type: "number", description: "Number of days to include in stats", defaultValue: "30" }
  ]}
/>

## Response

<TypeTable
  title="AnalyticsStats"
  properties={[
    { name: "period", type: "{ days: number, startDate: string, endDate: string }", required: true },
    { name: "summary", type: "{ totalViews, uniqueVisitors, avgViewsPerVisitor }", required: true },
    { name: "requestSource", type: "{ sdk: number, direct: number }", description: "Percentage breakdown" },
    { name: "topArticles", type: "Array<{ articleId, title, slug, views }>", required: true },
    { name: "topCountries", type: "Array<{ country, views }>", required: true }
  ]}
/>

## Example Request

<CurlCommand
  method="GET"
  url="https://api.simplist.blog/v1/analytics/stats?days=7"
  headers={{
    'X-API-Key': 'YOUR_API_KEY'
  }}
/>
