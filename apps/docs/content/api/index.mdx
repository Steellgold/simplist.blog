# API Reference

The Simplist API is a REST API that allows you to programmatically access and manage your blog content, analytics, and SEO features. All endpoints are served over HTTPS from `https://api.simplist.blog`.

<Callout type="info">
All API requests require authentication using an API key. Learn more in the [Authentication](/api/authentication) section.
</Callout>

## Base URL

```
https://api.simplist.blog
```

All endpoints are prefixed with `/v1`:

```
https://api.simplist.blog/v1/articles
```

## API Version

The current API version is **v1**. All endpoints are prefixed with `/v1` to ensure backwards compatibility as the API evolves.

## Quick Start

Here's a simple example of fetching your published articles:

```bash title="cURL"
curl https://api.simplist.blog/v1/articles?published=true \
  -H "X-API-Key: your_api_key_here"
```

```json title="Response"
{
  "data": [
    {
      "id": "clx1234567890",
      "title": "My First Article",
      "slug": "my-first-article",
      "excerpt": "This is my first article on Simplist",
      "status": "published",
      "publishedAt": "2024-01-15T10:30:00.000Z",
      "viewCount": 142,
      "readTimeMinutes": 5
    }
  ],
  "meta": {
    "total": 1,
    "page": 1,
    "limit": 10,
    "totalPages": 1
  }
}
```

## Authentication

All API requests require authentication using an API key passed in the `X-API-Key` header. You can create API keys in your project settings.

```bash
X-API-Key: your_api_key
```

<Callout type="warn">
Never expose API keys with read permission in client-side code. Use API keys with analytics permission for client-side analytics tracking.
</Callout>

Learn more about [API key permissions](/api/authentication).

## Rate Limiting

API requests are rate-limited based on your subscription tier:

- **STARTER**: 1,000 API calls per month
- **PRO**: 500,000 API calls per month

Rate limit information is included in response headers. See [Rate Limiting](/api/rate-limiting) for details.

## Pagination

List endpoints support pagination using `page` and `limit` query parameters. All paginated responses include metadata about total items and pages.

Learn more about [Pagination](/api/pagination).

## Error Handling

The API uses standard HTTP status codes and returns detailed error messages in JSON format:

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid API key"
  }
}
```

See [Error Reference](/api/errors) for complete error codes and handling strategies.
