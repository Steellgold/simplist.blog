# /v1/articles/:slug

Retrieve a single article by its unique slug identifier, including full content.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/articles/:slug"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    {
      name: "slug",
      type: "string",
      required: true,
      description: "Article slug (URL-friendly identifier)",
    },
    {
      name: "select",
      type: "string",
      required: false,
      description:
        'JSON object to customize response fields (e.g., {"variants":false})',
    },
  ]}
/>

## Path Parameters

<TypeTable
  properties={[
    {
      name: "slug",
      type: "string",
      description: "Unique article identifier (e.g., 'getting-started')",
      required: true,
    },
  ]}
/>

<TypeTable

## Field Selection

Customize which fields are included in the response. For example, exclude translation variants to reduce payload size:

<CurlCommand
  method="GET"
  url='https://api.simplist.blog/v1/articles/getting-started?select={"variants":false}'
  headers={{
    "X-API-Key": "YOUR_API_KEY",
  }}
/>

Or include tag metadata:

<CurlCommand
  method="GET"
  url='https://api.simplist.blog/v1/articles/getting-started?select={"tagColor":true,"tagIcon":true}'
  headers={{
    "X-API-Key": "YOUR_API_KEY",
  }}
/>

See the [GET /v1/articles](/api/get-articles#field-selection) endpoint documentation for a full list of available fields.
