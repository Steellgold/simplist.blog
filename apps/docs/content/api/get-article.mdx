# /v1/articles/:slug

Retrieve a single article by its unique slug identifier, including full content.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/articles/:slug"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    { name: "slug", type: "string", required: true, description: "Article slug (URL-friendly identifier)" }
  ]}
/>

## Path Parameters

<TypeTable
  properties={[
    { name: "slug", type: "string", description: "Unique article identifier (e.g., 'getting-started')", required: true }
  ]}
/>

## Response

Returns a complete `Article` object with full content.

<TypeTable
  title="Article"
  properties={[
    { name: "id", type: "string", required: true },
    { name: "title", type: "string", required: true },
    { name: "slug", type: "string", required: true },
    { name: "content", type: "string", description: "Full Markdown content", required: true },
    { name: "excerpt", type: "string | null" },
    { name: "coverImage", type: "string | null" },
    { name: "published", type: "boolean", required: true },
    { name: "viewCount", type: "number", required: true },
    { name: "readTimeMinutes", type: "number", required: true },
    { name: "author", type: "Author", required: true },
    { name: "createdAt", type: "string", required: true },
    { name: "publishedAt", type: "string | null" }
  ]}
/>

## Example Request

<CurlCommand
