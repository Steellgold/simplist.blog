# /v1/tags/:name

Retrieve a specific tag by its name with article count and metadata.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/tags/:name"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
/>

## Path Parameters

<TypeTable
  title="Parameters"
  properties={[
    {
      name: "name",
      type: "string",
      description: "The tag name (URL-encoded if contains special characters)",
      required: true,
    },
  ]}
/>

## Response

Returns a single `TagListItem` object.

<TypeTable
  title="TagListItem"
  properties={[
    {
      name: "id",
      type: "string",
      description: "Unique tag identifier",
      required: true,
    },
    { name: "name", type: "string", description: "Tag name", required: true },
    {
      name: "icon",
      type: "string | null",
      description: "Tag icon name (e.g., 'code', 'book')",
    },
    {
      name: "color",
      type: "string | null",
      description: "Hex color code (e.g., '#3B82F6')",
    },
    {
      name: "articleCount",
      type: "number",
      description: "Number of articles with this tag",
      required: true,
    },
    {
      name: "createdAt",
      type: "string",
      description: "ISO 8601 creation timestamp",
      required: true,
    },
    {
      name: "updatedAt",
      type: "string",
      description: "ISO 8601 last update timestamp",
      required: true,
    },
  ]}
/>

## Example Request

<CurlCommand
  method="GET"
  url="https://api.simplist.blog/v1/tags/JavaScript"
  headers={{
    "X-API-Key": "YOUR_API_KEY",
  }}
/>

### URL-Encoding Special Characters

For tags with spaces or special characters, URL-encode the name:

<CurlCommand
  method="GET"
  url="https://api.simplist.blog/v1/tags/Machine%20Learning"
  headers={{
    "X-API-Key": "YOUR_API_KEY",
  }}
/>
