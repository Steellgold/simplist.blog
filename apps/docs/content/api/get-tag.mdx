# /v1/tags/:name

Retrieve a specific tag by its name with article count and metadata.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/tags/:name"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
/>

## Path Parameters

<TypeTable
  title="Parameters"
  properties={[
    { name: "name", type: "string", description: "The tag name (URL-encoded if contains special characters)", required: true }
  ]}
/>

## Response

Returns a single `TagListItem` object.

<TypeTable
  title="TagListItem"
  properties={[
    { name: "id", type: "string", description: "Unique tag identifier", required: true },
    { name: "name", type: "string", description: "Tag name", required: true },
    { name: "icon", type: "string | null", description: "Tag icon name (e.g., 'code', 'book')" },
    { name: "color", type: "string | null", description: "Hex color code (e.g., '#3B82F6')" },
    { name: "articleCount", type: "number", description: "Number of articles with this tag", required: true },
    { name: "createdAt", type: "string", description: "ISO 8601 creation timestamp", required: true },
    { name: "updatedAt", type: "string", description: "ISO 8601 last update timestamp", required: true }
  ]}
/>

## Example Request

<CodeBlock language="bash">
{`curl -X GET "https://api.simplist.blog/v1/tags/JavaScript" \\
  -H "X-API-Key: YOUR_API_KEY"`}
</CodeBlock>

### URL-Encoding Special Characters

For tags with spaces or special characters, URL-encode the name:

<CodeBlock language="bash">
{`# Tag name: "Machine Learning"
curl -X GET "https://api.simplist.blog/v1/tags/Machine%20Learning" \\
  -H "X-API-Key: YOUR_API_KEY"`}
</CodeBlock>

## Example Response

<CodeBlock language="json">
{`
  {
    "data": {
      "id": "tag_abc123",
      "name": "JavaScript",
      "icon": "code",
      "color": "#F7DF1E",
      "articleCount": 12,
      "createdAt": "2024-01-15T10:30:00Z",
      "updatedAt": "2025-12-09T08:15:00Z"
    }
  }
`}
</CodeBlock>

## Error Responses

### Tag Not Found (404)

<CodeBlock language="json">
{`
  {
    "error": "Not Found",
    "message": "Tag not found",
    "statusCode": 404
  }
`}
</CodeBlock>
