# Article SEO Metadata

Fetch an article with complete SEO metadata including meta tags, Open Graph, Twitter Card, and Schema.org structured data.

```http
GET /v1/seo/article/:articleSlug
GET /v1/seo/article/:articleSlug/:lang
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `articleSlug` | string | Yes | Article slug |
| `lang` | string | No | Language code for variant (e.g., `fr`, `es`) |

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `baseUrl` | string | Recommended | Base URL for generating absolute URLs |

<Callout type="warn">
The `baseUrl` parameter is highly recommended for proper SEO. Without it, URLs in metadata may be relative.
</Callout>

## Multi-Language Variant

Get SEO metadata for a specific language:

```bash
curl "https://api.simplist.blog/v1/seo/article/getting-started/fr?baseUrl=https://myblog.com" \
  -H "X-API-Key: your_api_key"
```

The response will include SEO metadata for the French variant with translated content.

## Usage in HTML

### Meta Tags

```html
<head>
  <title>${seo.title}</title>
  <meta name="description" content="${seo.description}" />
  <link rel="canonical" href="${seo.canonical}" />

  <!-- Open Graph -->
  <meta property="og:title" content="${seo.openGraph.title}" />
  <meta property="og:description" content="${seo.openGraph.description}" />
  <meta property="og:type" content="${seo.openGraph.type}" />
  <meta property="og:url" content="${seo.openGraph.url}" />
  <meta property="og:image" content="${seo.openGraph.image}" />
  <meta property="og:site_name" content="${seo.openGraph.siteName}" />

  <!-- Twitter Card -->
  <meta name="twitter:card" content="${seo.twitter.card}" />
  <meta name="twitter:title" content="${seo.twitter.title}" />
  <meta name="twitter:description" content="${seo.twitter.description}" />
  <meta name="twitter:image" content="${seo.twitter.image}" />

  <!-- Structured Data -->
  <script type="application/ld+json">
    ${JSON.stringify(seo.structuredData)}
  </script>
</head>
```

### Next.js Metadata API

```typescript
// app/articles/[slug]/page.tsx
import { Metadata } from 'next';

export async function generateMetadata({
  params
}: {
  params: { slug: string }
}): Promise<Metadata> {
  const response = await fetch(
    `https://api.simplist.blog/v1/seo/article/${params.slug}?baseUrl=https://myblog.com`,
    {
      headers: { 'X-API-Key': process.env.SIMPLIST_API_KEY! },
      next: { revalidate: 300 } // Revalidate every 5 minutes
    }
  );

  if (!response.ok) {
    return {
      title: 'Article Not Found',
    };
  }

  const article = await response.json();
  const { seo } = article;

  return {
    title: seo.title,
    description: seo.description,
    alternates: {
      canonical: seo.canonical,
    },
    openGraph: {
      title: seo.openGraph.title,
      description: seo.openGraph.description,
      url: seo.openGraph.url,
      images: [
        {
          url: seo.openGraph.image,
        },
      ],
      type: 'article',
      siteName: seo.openGraph.siteName,
    },
    twitter: {
      card: 'summary_large_image',
      title: seo.twitter.title,
      description: seo.twitter.description,
      images: [seo.twitter.image],
    },
  };
}
```

## Caching

SEO metadata responses are cached for **5 minutes**. Cache is invalidated when articles are updated.
