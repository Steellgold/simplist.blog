# RSS Feed Generation

Generate RSS 2.0 feeds for your blog to enable content syndication and allow readers to subscribe.

```http
GET /v1/seo/rss
```

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `baseUrl` | string | **Yes** | Base URL for your blog |
| `limit` | number | No | Max articles (1-100, default: 20) |
| `lang` | string | No | Filter by language code |
| `customPath` | string | No | Custom URL path pattern |

async function getRSSFeed(limit: number = 20): Promise<string> {
  const response = await fetch(
    `https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&limit=${limit}`,

## Custom URL Paths

Customize article URLs in the feed:

```bash
# Default: uses project slug
curl "https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com"

# Custom path
curl "https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&customPath=blog/{slug}"
```

## Filter by Language

Generate RSS feed for specific language:

```bash
curl "https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&lang=fr" \
  -H "X-API-Key: your_api_key"
```

## Limit Articles

Control number of articles in feed:

```bash
# Latest 10 articles
curl "https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&limit=10" \
  -H "X-API-Key: your_api_key"

# Latest 50 articles
curl "https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&limit=50" \
  -H "X-API-Key: your_api_key"
```

<Callout type="info">
Maximum limit is **100 articles**. Requests with higher limits will be capped at 100.
</Callout>

## Next.js RSS Route

Create an RSS feed route in Next.js:

```typescript
// app/rss.xml/route.ts
import { NextResponse } from 'next/server';

export async function GET() {
  const response = await fetch(
    `https://api.simplist.blog/v1/seo/rss?baseUrl=${process.env.NEXT_PUBLIC_BASE_URL}&limit=50`,
    {
      headers: {
        'X-API-Key': process.env.SIMPLIST_API_KEY!,
      },
      next: { revalidate: 3600 }, // Revalidate every hour
    }
  );

  const rss = await response.text();

  return new NextResponse(rss, {
    headers: {
      'Content-Type': 'application/rss+xml; charset=utf-8',
      'Cache-Control': 'public, max-age=3600, s-maxage=3600',
    },
  });
}
```

Access at: `https://myblog.com/rss.xml`

## RSS Feed Structure

### Channel Fields

| Field | Description |
|-------|-------------|
| `title` | Project name |
| `link` | Project URL |
| `description` | "Latest articles from \{project name\}" |
| `language` | Language code (e.g., `en`, `fr`) |
| `lastBuildDate` | Feed generation timestamp |
| `atom:link` | Self-referencing feed URL |

### Item Fields

| Field | Description |
|-------|-------------|
| `title` | Article title |
| `link` | Full article URL |
| `description` | Article excerpt |
| `pubDate` | Publication date (RFC 822 format) |
| `guid` | Unique identifier (article URL) |

## Dynamic Updates

RSS feeds automatically include:
- Latest published articles
- Ordered by publication date (newest first)
- Only published articles (drafts excluded)

Changes appear after 5-minute cache expires.

## Error Responses

  }

```

### 401 Unauthorized

  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid API key"
  }

```

## Caching

RSS feeds are cached for **5 minutes**. Cache is invalidated when articles are created, updated, or deleted.

## Best Practices

### 1. Always Provide Base URL

```typescript
// Good
const url = 'https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com';

// Bad - missing baseUrl
const url = 'https://api.simplist.blog/v1/seo/rss';
```

### 2. Use Reasonable Limits

```typescript
// Good - reasonable feed size
limit: 20  // or 50

// Avoid - too large
limit: 100 // Slow for readers
```

### 3. Add RSS Discovery

Help readers find your RSS feed:

```html
<!-- In <head> -->
<link rel="alternate" type="application/rss+xml" href="/rss.xml" />

<!-- Visible link -->
<a href="/rss.xml">Subscribe via RSS</a>
```

### 4. Validate Your Feed

Test your RSS feed:
- [W3C Feed Validation Service](https://validator.w3.org/feed/)
- [RSS Feed Validator](https://www.rssboard.org/rss-validator/)

### 5. Monitor Subscribers

Track RSS feed requests in analytics to understand subscriber growth.

## Multi-Language Feeds

Create separate feeds for each language:

```html
<link rel="alternate" type="application/rss+xml" title="English Feed"
      href="https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&lang=en" />

      href="https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&lang=fr" />
```
