# Structured Data

Get Schema.org JSON-LD structured data for all published articles in your project.

```http
GET /v1/seo/structured-data
```

<Callout type="info">
Structured data helps search engines understand your content and can enable rich results in search.
</Callout>

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `baseUrl` | string | - | Base URL for generating absolute URLs |
| `limit` | number | `200` | Max articles to return (1-500) |
| `offset` | number | `0` | Number of articles to skip (pagination) |

## Pagination

For projects with many articles, use pagination:

```bash
# First 200 articles
curl "https://api.simplist.blog/v1/seo/structured-data?baseUrl=https://myblog.com&limit=200&offset=0"

# Next 200 articles
curl "https://api.simplist.blog/v1/seo/structured-data?baseUrl=https://myblog.com&limit=200&offset=200"

# Next 200 articles
curl "https://api.simplist.blog/v1/seo/structured-data?baseUrl=https://myblog.com&limit=200&offset=400"
```

## Next.js Implementation

### Static Generation

```typescript
// app/articles/[slug]/page.tsx
import { Metadata } from 'next';

// Get all articles for static generation
export async function generateStaticParams() {
  const response = await fetch(
    `https://api.simplist.blog/v1/seo/structured-data?baseUrl=${process.env.NEXT_PUBLIC_BASE_URL}`,
    {
      headers: { 'X-API-Key': process.env.SIMPLIST_API_KEY! },
    }
  );

  const { articles } = await response.json();

  return articles.map((article) => ({
    slug: article.slug,
  }));
}

// Generate page with structured data
export default async function ArticlePage({
  params,
}: {
  params: { slug: string };
}) {
  const response = await fetch(
    `https://api.simplist.blog/v1/seo/structured-data?baseUrl=${process.env.NEXT_PUBLIC_BASE_URL}`,
    {
      headers: { 'X-API-Key': process.env.SIMPLIST_API_KEY! },
      next: { revalidate: 3600 },
    }
  );

  const { articles } = await response.json();
  const article = articles.find((a) => a.slug === params.slug);

  if (!article) {
    return <div>Article not found</div>;
  }

  return (
    <>
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: JSON.stringify(article.structuredData),
        }}
      />

      <article>
        <h1>{article.structuredData.headline}</h1>
        {/* Article content */}
      </article>
    </>
  );
}
```

## Schema.org Fields

### Article Schema

| Field | Type | Description |
|-------|------|-------------|
| `@context` | string | Always `https://schema.org` |
| `@type` | string | Always `Article` |
| `headline` | string | Article title |
| `description` | string | Article excerpt |
| `image` | string | Cover image URL |
| `datePublished` | string | Publication date (ISO 8601) |
| `dateModified` | string | Last modified date (ISO 8601) |
| `author` | object | Author information |

### Author Schema

| Field | Type | Description |
|-------|------|-------------|
| `@type` | string | Always `Person` |
| `name` | string | Author's full name |

## Caching

Structured data responses are cached for **5 minutes**. Cache is invalidated when articles are updated.

## Best Practices

### 1. Include All Required Fields

Ensure your articles have:
- Title (headline)
- Description (excerpt)
- Cover image
- Author information
- Publication date

### 2. Use High-Quality Images

- Minimum 1200px wide
- Aspect ratio 16:9 or 4:3
- JPEG or PNG format

### 3. Keep Descriptions Under 200 Characters

Optimal for search result snippets.

### 4. Update Modified Dates

Ensure `dateModified` updates when articles change.

### 5. Validate Before Publishing

Always test with Google's Rich Results Test.

## Batch Processing

For large projects with 500+ articles:

```typescript
async function getAllStructuredData() {
  const allArticles = [];
  let offset = 0;
  const limit = 500; // Max allowed

  while (true) {
    const response = await fetch(
      `https://api.simplist.blog/v1/seo/structured-data?baseUrl=https://myblog.com&limit=${limit}&offset=${offset}`,
      { headers: { 'X-API-Key': apiKey } }
    );

    const { articles } = await response.json();

    if (articles.length === 0) break;

    allArticles.push(...articles);
    offset += limit;

    if (articles.length < limit) break; // Last page
  }

  return allArticles;
}
```
