# /v1/seo/rss

Generate an RSS 2.0 feed for your published articles.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/seo/rss"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    { name: "baseUrl", type: "string", required: true, description: "Base URL for article links" },
    { name: "limit", type: "number", required: false, description: "Number of articles to include (default: 20)" },
    { name: "path", type: "string", required: false, description: "Path prefix for articles" }
  ]}
/>

## Query Parameters

<TypeTable
  properties={[
    { name: "baseUrl", type: "string", description: "Base URL for all links", required: true },
    { name: "limit", type: "number", description: "Number of articles", defaultValue: "20" },
    { name: "path", type: "string", description: "Path prefix (e.g., 'blog')" }
  ]}
/>

## Response

Returns RSS 2.0 XML feed.

## Example Request

<CurlCommand
  method="GET"
  url="https://api.simplist.blog/v1/seo/rss?baseUrl=https://myblog.com&limit=50&path=blog"
  headers={{
    'X-API-Key': 'YOUR_API_KEY'
  }}
/>
