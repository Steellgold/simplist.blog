# Projects API

The Projects API allows you to fetch information about your project and retrieve statistics about your content and engagement.

<Callout type="info">
The project is automatically determined from your API key. Each API key belongs to a specific project.
</Callout>

## Project Object

```json
{
  "project": {
    "id": "clx1234567890",
    "name": "My Blog",
    "slug": "my-blog",
    "createdAt": "2024-01-01T00:00:00.000Z",
    "updatedAt": "2024-01-15T10:30:00.000Z"
  },
  "stats": {
    "totalArticles": 42,
    "publishedArticles": 35,
    "totalViews": 15847
  }
}
```

### Project Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique project identifier |
| `name` | string | Project name |
| `slug` | string | URL-friendly project slug |
| `createdAt` | string | Creation timestamp (ISO 8601) |
| `updatedAt` | string | Last update timestamp (ISO 8601) |

### Statistics Fields

| Field | Type | Description |
|-------|------|-------------|
| `totalArticles` | number | Total articles (excluding deleted) |
| `publishedArticles` | number | Number of published articles |
| `totalViews` | number | Total page views across all articles |

## Common Use Cases

### Display Project Stats

Show project statistics on your dashboard:

```typescript
const response = await fetch('https://api.simplist.blog/v1/project', {
  headers: { 'X-API-Key': apiKey }
});

const { data } = await response.json();

console.log(`Project: ${data.project.name}`);
console.log(`Articles: ${data.stats.publishedArticles} published`);
console.log(`Total Views: ${data.stats.totalViews}`);
```

### Monitor Content Growth

Track article count over time:

```typescript
async function getArticleCount() {
  const response = await fetch('https://api.simplist.blog/v1/project', {
    headers: { 'X-API-Key': apiKey }
  });

  const { data } = await response.json();
  return data.stats.totalArticles;
}
```

### Verify API Key

Use the project endpoint to verify your API key is valid:

```typescript
async function verifyApiKey(apiKey: string): Promise<boolean> {
  try {
    const response = await fetch('https://api.simplist.blog/v1/project', {
      headers: { 'X-API-Key': apiKey }
    });

    return response.ok;
  } catch {
    return false;
  }
}
```
