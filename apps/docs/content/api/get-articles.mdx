# /v1/articles

Retrieve a list of articles from your Simplist project with pagination, filtering, and sorting options.

## Endpoint

<ApiPath
  method="GET"
  path="/v1/articles"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    { name: "page", type: "number", required: false, description: "Page number (default: 1)" },
    { name: "limit", type: "number", required: false, description: "Items per page (default: 10, max: 100)" },
    { name: "sort", type: "string", required: false, description: "Sort field: createdAt | updatedAt | title" },
    { name: "order", type: "string", required: false, description: "Sort order: asc | desc (default: desc)" },
    { name: "published", type: "boolean", required: false, description: "Filter by published status" },
    { name: "search", type: "string", required: false, description: "Search query for title/content" },
    { name: "status", type: "string", required: false, description: "Filter by status: draft | published" }
  ]}
/>

## Query Parameters

<TypeTable
  properties={[
    { name: "page", type: "number", description: "Page number for pagination", defaultValue: "1" },
    { name: "limit", type: "number", description: "Number of items per page", defaultValue: "10" },
    { name: "sort", type: "string", description: "Field to sort by", defaultValue: "createdAt" },
    { name: "order", type: "string", description: "Sort direction (asc or desc)", defaultValue: "desc" },
    { name: "published", type: "boolean", description: "Filter by published status" },
    { name: "search", type: "string", description: "Search in title and content" },
    { name: "status", type: "string", description: "Filter by article status" }
  ]}
/>

## Response

Returns an array of `ArticleListItem` objects (articles without full content).

<TypeTable
  title="ArticleListItem"
  properties={[
    { name: "id", type: "string", description: "Unique article identifier", required: true },
    { name: "title", type: "string", description: "Article title", required: true },
    { name: "slug", type: "string", description: "URL-friendly article identifier", required: true },
    { name: "excerpt", type: "string | null", description: "Short article summary" },
    { name: "coverImage", type: "string | null", description: "Cover image URL" },
    { name: "published", type: "boolean", description: "Publication status", required: true },
    { name: "viewCount", type: "number", description: "Number of views", required: true },
    { name: "readTimeMinutes", type: "number", description: "Estimated reading time", required: true },
    { name: "createdAt", type: "string", description: "ISO 8601 creation date", required: true },
    { name: "publishedAt", type: "string | null", description: "ISO 8601 publication date" }
  ]}
/>

## Example

<CodeBlock language="bash">
{`
  curl -X GET "https://api.simplist.blog/v1/articles?page=1&limit=5&published=true" \
    
    -H "X-API-Key: YOUR_API_KEY"
`}
