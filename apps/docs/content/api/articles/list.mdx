# List Articles

Fetch a paginated list of articles from your project.

```http
GET /v1/articles
```

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | integer | `1` | Page number (1-indexed) |
| `limit` | integer | `20` | Items per page (max: 100) |
| `sort` | string | `createdAt` | Sort field |
| `order` | string | `desc` | Sort order: `asc` or `desc` |
| `published` | boolean | `true` | Filter by published status |
| `search` | string | - | Search in title, excerpt, and content |
| `status` | string | - | Filter by status: `draft`, `published` |

### Sort Fields

You can sort articles by any of these fields:

- `createdAt` - Creation date
- `updatedAt` - Last update date
- `publishedAt` - Publication date
- `title` - Article title
- `viewCount` - Number of views
- `readTimeMinutes` - Reading time

## Use Cases

### Latest Articles

Fetch the 5 most recent published articles:

```bash
curl "https://api.simplist.blog/v1/articles?published=true&sort=publishedAt&order=desc&limit=5" \
  -H "X-API-Key: your_api_key"
```

### Most Popular Articles

Fetch articles sorted by view count:

```bash
curl "https://api.simplist.blog/v1/articles?sort=viewCount&order=desc&limit=10" \
  -H "X-API-Key: your_api_key"
```

### Search Articles

Search for articles containing "TypeScript":

```bash
curl "https://api.simplist.blog/v1/articles?search=TypeScript" \
  -H "X-API-Key: your_api_key"
```

The search looks in:
- Article title
- Article excerpt
- Article content

<Callout type="info">
Search is case-insensitive and performs a partial match.
</Callout>

### Filter by Status

Fetch only draft articles (requires API key with read permission):

```bash
curl "https://api.simplist.blog/v1/articles?status=draft&published=false" \
  -H "X-API-Key: your_api_key"
```

### Pagination

Fetch page 2 with 20 articles per page:

```bash
curl "https://api.simplist.blog/v1/articles?page=2&limit=20" \
  -H "X-API-Key: your_api_key"
```

See [Pagination](/api/pagination) for more details.

## Response Fields

### Article Object

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier |
| `title` | string | Article title |
| `slug` | string | URL-friendly slug |
| `excerpt` | string \| null | Short summary |
| `coverImage` | string \| null | Cover image URL |
| `published` | boolean | Published status |
| `status` | string | `draft` or `published` |
| `viewCount` | number | Total views |
| `wordCount` | number | Word count |
| `characterCount` | number | Character count |
| `lineCount` | number | Line count |
| `readTimeMinutes` | number | Reading time estimate |
| `createdAt` | string | ISO 8601 timestamp |
| `updatedAt` | string | ISO 8601 timestamp |
| `publishedAt` | string \| null | ISO 8601 timestamp |
| `author` | object \| null | Author information |
| `lastUpdatedBy` | object \| null | Last editor information |

### Metadata Object

| Field | Type | Description |
|-------|------|-------------|
| `page` | number | Current page number |
| `limit` | number | Items per page |
| `total` | number | Total number of articles |
| `totalPages` | number | Total number of pages |

## Caching

List responses are cached for **5 minutes** based on query parameters. Cache is automatically invalidated when:

- An article is created
- An article is updated
- An article is deleted
