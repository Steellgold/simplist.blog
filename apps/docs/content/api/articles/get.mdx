# Get Article

Fetch a single article by its slug, including full content and multi-language variants.

```http
GET /v1/articles/:slug
```

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `slug` | string | Yes | Article URL slug |

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `includeSeo` | boolean | `false` | Include SEO metadata in response |
| `baseUrl` | string | - | Base URL for SEO metadata generation |

## Including SEO Metadata

Request SEO metadata with the article:

<Tabs items={['cURL', 'JavaScript']}>
<Tab value="cURL">
```bash
curl "https://api.simplist.blog/v1/articles/getting-started?includeSeo=true&baseUrl=https://myblog.com" \
  -H "X-API-Key: your_api_key"
```
</Tab>
<Tab value="JavaScript">
```javascript
const response = await fetch(
  `https://api.simplist.blog/v1/articles/${slug}?includeSeo=true&baseUrl=https://myblog.com`,
  { headers: { 'X-API-Key': apiKey } }
);

const { data } = await response.json();

// Use SEO metadata
const { seo } = data;
console.log(seo.title); // Page title
console.log(seo.openGraph); // Open Graph tags
console.log(seo.twitter); // Twitter Card tags
```

## Working with Variants

Multi-language variants are included in the response for PRO projects:

```typescript
const { data: article } = await response.json();

// Get French variant
const frenchVariant = article.variants.find(v => v.lang === 'fr');

if (frenchVariant) {
  console.log(frenchVariant.title); // French title
  console.log(frenchVariant.content); // French content
}

// List all available languages
const languages = article.variants.map(v => v.lang);
console.log('Available in:', ['en', ...languages]);
```

<Callout type="info">
Variants are a **PRO** feature. STARTER projects will have an empty `variants` array.
</Callout>

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Unique identifier |
| `title` | string | Article title |
| `slug` | string | URL-friendly slug |
| `excerpt` | string \| null | Short summary |
| `content` | string | Full Markdown content |
| `coverImage` | string \| null | Cover image URL |
| `published` | boolean | Published status |
| `status` | string | `draft`, `published`, or `scheduled` |
| `viewCount` | number | Total page views |
| `wordCount` | number | Word count |
| `characterCount` | number | Character count |
| `lineCount` | number | Line count |
| `readTimeMinutes` | number | Estimated reading time |
| `createdAt` | string | ISO 8601 timestamp |
| `updatedAt` | string | ISO 8601 timestamp |
| `publishedAt` | string \| null | ISO 8601 timestamp |
| `author` | object \| null | Author information |
| `lastUpdatedBy` | object \| null | Last editor information |
| `variants` | array | Multi-language variants |

## Error Responses

### 404 Not Found

Article doesn't exist or is not published:

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Article not found or not published"
  }
}
```

<Callout type="warn">
Only **published** articles are accessible via the public API. Draft and scheduled articles return a 404 error.
</Callout>

### 401 Unauthorized

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid API key"
  }
}
```

### 500 Internal Server Error

```json
{
  "error": {
    "code": "INTERNAL_ERROR",
    "message": "Failed to fetch article"
  }
}
```

## Caching

Individual articles are cached for **5 minutes** by slug. Cache is automatically invalidated when the article is updated or deleted.

## Use Cases

### Display Article Page

```typescript
async function getArticlePage(slug: string) {
  const response = await fetch(
    `https://api.simplist.blog/v1/articles/${slug}`,
    { headers: { 'X-API-Key': apiKey } }
  );

  if (response.status === 404) {
    return null; // Article not found
  }

  const { data: article } = await response.json();
  return article;
}
```

### Render Markdown Content

```typescript
import { marked } from 'marked';

const { data: article } = await response.json();

// Convert Markdown to HTML
const htmlContent = marked(article.content);
```

### Multi-Language Support

```typescript
function getArticleContent(article: Article, lang: string = 'en') {
  if (lang === 'en') {
    return {
      title: article.title,
      content: article.content,
      excerpt: article.excerpt
    };
  }

  const variant = article.variants.find(v => v.lang === lang);

  return variant ? {
    title: variant.title,
    content: variant.content,
    excerpt: variant.excerpt
  } : null;
}

// Usage
const content = getArticleContent(article, 'fr');
```
