# Track Page View

Create a new page view record and optionally track custom events.

```http
POST /v1/analytics/track
```

<Callout type="info">
This endpoint requires an API key with **analytics** permission, making it safe for client-side tracking.
</Callout>

## Request Body

### Required Fields

| Field | Type | Description |
|-------|------|-------------|
| `articleSlug` | string | Article slug to track |

### Visitor Tracking

| Field | Type | Description |
|-------|------|-------------|
| `visitorId` | string | Unique visitor ID (recommended, must start with `visitor_`) |
| `sessionId` | string | Session ID (auto-generated if not provided) |

### Page Information

| Field | Type | Description |
|-------|------|-------------|
| `pageUrl` | string | Full page URL |
| `pageTitle` | string | Page title (defaults to article title) |
| `referrer` | string | Referrer URL |

### Device Information

| Field | Type | Description |
|-------|------|-------------|
| `screenWidth` | number | Screen width in pixels |
| `screenHeight` | number | Screen height in pixels |

### Geographic Data

| Field | Type | Description |
|-------|------|-------------|
| `country` | string | Country name |
| `countryCode` | string | ISO country code (e.g., `US`, `FR`) |
| `region` | string | Region/state name |
| `city` | string | City name |
| `timezone` | string | Timezone (e.g., `America/New_York`) |

### UTM Parameters

| Field | Type | Description |
|-------|------|-------------|
| `utmSource` | string | Campaign source |
| `utmMedium` | string | Campaign medium |
| `utmCampaign` | string | Campaign name |
| `utmTerm` | string | Campaign term |
| `utmContent` | string | Campaign content |

### Engagement Metrics

| Field | Type | Description |
|-------|------|-------------|
| `timeOnPage` | number | Time spent on page (seconds) |
| `scrollDepth` | number | Scroll depth percentage (0-100) |
| `exitPosition` | number | Scroll position when exiting |
| `bounced` | boolean | Whether user bounced |

### Custom Events

| Field | Type | Description |
|-------|------|-------------|
| `events` | array | Array of custom event objects |

Each event object:

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | Event type (e.g., `click`, `scroll`) |
| `data` | object | Custom event data |
| `position` | number | Scroll position when event occurred |
| `element` | string | Element identifier |
| `timestamp` | string | ISO 8601 timestamp |
| `timeOffset` | number | Milliseconds from page load |

## Response

```json
{
  "success": true,
  "pageViewId": "clx1234567890",
  "visitorId": "visitor_abc123",
  "sessionId": "session_xyz789"
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | Always `true` on success |
| `pageViewId` | string | Unique ID for this page view (use for updates) |
| `visitorId` | string | Visitor ID (returned or generated) |
| `sessionId` | string | Session ID (returned or generated) |

<Callout type="info">
Store the `pageViewId` to update engagement metrics when the user leaves the page.
</Callout>

## Tracking Custom Events

Track user interactions like clicks, scroll milestones, or video plays:

```javascript
await fetch('https://api.simplist.blog/v1/analytics/track', {
  method: 'POST',
  headers: {
    'X-API-Key': 'your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    articleSlug: 'getting-started',
    visitorId,
    sessionId,
    pageUrl: window.location.href,
    events: [
      {
        type: 'scroll',
        position: 50,
        timeOffset: 30000 // 30 seconds after page load
      },
      {
        type: 'click',
        element: 'cta-button',
        data: { buttonText: 'Get Started' },
        timeOffset: 45000
      },
      {
        type: 'video_play',
        element: 'intro-video',
        data: { duration: 120 },
        timeOffset: 60000
      }
    ]
  })
});
```

## Bot Detection

The API automatically detects and rejects bot traffic:

```json
{
  "error": {
    "code": "BOT_DETECTED",
    "message": "Analytics tracking is not available for automated requests"
  }
}
```

Detected bots include:
- Search engines (Googlebot, Bingbot, Yandex, Baidu)
- Social media crawlers (Facebookbot, Twitterbot, LinkedInBot)
- Developer tools (curl, wget, Postman, Insomnia)
- Monitoring services (UptimeRobot, Pingdom, StatusCake)

## Best Practices

### Generate Stable Visitor IDs

```typescript
function getOrCreateVisitorId(): string {
  const STORAGE_KEY = 'simplist_visitor_id';
  let visitorId = localStorage.getItem(STORAGE_KEY);

  if (!visitorId) {
    visitorId = `visitor_${Date.now()}_${crypto.randomUUID()}`;
    localStorage.setItem(STORAGE_KEY, visitorId);
  }

  return visitorId;
}
```

### Generate Session IDs

```typescript
function getOrCreateSessionId(): string {
  const STORAGE_KEY = 'simplist_session_id';
  let sessionId = sessionStorage.getItem(STORAGE_KEY);

  if (!sessionId) {
    sessionId = `session_${Date.now()}_${crypto.randomUUID()}`;
    sessionStorage.setItem(STORAGE_KEY, sessionId);
  }

  return sessionId;
}
```

### Extract UTM Parameters

```typescript
function getUTMParams() {
  const params = new URLSearchParams(window.location.search);

  return {
    utmSource: params.get('utm_source') || undefined,
    utmMedium: params.get('utm_medium') || undefined,
    utmCampaign: params.get('utm_campaign') || undefined,
    utmTerm: params.get('utm_term') || undefined,
    utmContent: params.get('utm_content') || undefined
  };
}
```

### Complete Tracking Example

```typescript
async function trackPageView(articleSlug: string) {
  try {
    const response = await fetch('https://api.simplist.blog/v1/analytics/track', {
      method: 'POST',
      headers: {
        'X-API-Key': process.env.NEXT_PUBLIC_SIMPLIST_API_KEY!,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        articleSlug,
        visitorId: getOrCreateVisitorId(),
        sessionId: getOrCreateSessionId(),
        pageUrl: window.location.href,
        referrer: document.referrer,
        screenWidth: window.screen.width,
        screenHeight: window.screen.height,
        ...getUTMParams()
      })
    });

    if (!response.ok) {
      console.error('Failed to track page view');
      return null;
    }

    const { pageViewId } = await response.json();
    return pageViewId;
  } catch (error) {
    console.error('Error tracking page view:', error);
    return null;
  }
}
```
