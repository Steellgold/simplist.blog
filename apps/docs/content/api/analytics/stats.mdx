# Get Analytics Statistics

Retrieve aggregated analytics statistics for your project, including views, visitors, top articles, and geographic data.

```http
GET /v1/analytics/stats
```

<Callout type="warn">
This endpoint requires an API key with **read** permission.
</Callout>

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `days` | number | `30` | Number of days to include in stats |

## Response Fields

### Period

| Field | Type | Description |
|-------|------|-------------|
| `days` | number | Number of days included |
| `startDate` | string | Start date (ISO 8601) |
| `endDate` | string | End date (ISO 8601) |

### Summary

| Field | Type | Description |
|-------|------|-------------|
| `totalViews` | number | Total page views in period |
| `uniqueVisitors` | number | Unique visitors (deduplicated) |
| `avgViewsPerVisitor` | number | Average views per visitor |

### Request Source

Breakdown of traffic by source:

| Field | Type | Description |
|-------|------|-------------|
| `sdk.count` | number | Views from SDK |
| `sdk.percentage` | number | Percentage from SDK (0-100) |
| `direct.count` | number | Views from direct implementation |
| `direct.percentage` | number | Percentage from direct (0-100) |

### Top Articles

Array of most viewed articles (max 10):

| Field | Type | Description |
|-------|------|-------------|
| `articleId` | string | Article ID |
| `title` | string | Article title |
| `slug` | string | Article slug |
| `views` | number | Number of views |

### Top Countries

Array of countries with most views (max 10):

| Field | Type | Description |
|-------|------|-------------|
| `country` | string | Country name |
| `views` | number | Number of views from this country |

## Use Cases

### Analytics Dashboard

Build a comprehensive analytics dashboard:

```typescript
async function getAnalyticsDashboard(days: number = 30) {
  const response = await fetch(
    `https://api.simplist.blog/v1/analytics/stats?days=${days}`,
    { headers: { 'X-API-Key': apiKey } }
  );

  const stats = await response.json();

  return {
    overview: {
      totalViews: stats.summary.totalViews,
      uniqueVisitors: stats.summary.uniqueVisitors,
      avgViewsPerVisitor: stats.summary.avgViewsPerVisitor
    },
    topArticles: stats.topArticles.slice(0, 5),
    topCountries: stats.topCountries.slice(0, 5),
    trafficSources: {
      sdk: stats.requestSource.sdk,
      direct: stats.requestSource.direct
    }
  };
}
```

### Track Content Performance

Identify your best performing content:

```typescript
async function getTopPerformers() {

    'https://api.simplist.blog/v1/analytics/stats?days=7',

    rank: index + 1,
    title: article.title,
    slug: article.slug,

  }));
}
```

### Geographic Insights

Analyze your audience location:

```typescript
async function getGeographicDistribution() {

    'https://api.simplist.blog/v1/analytics/stats?days=30',
    { headers: { 'X-API-Key': apiKey } }
  );

  const stats = await response.json();

  const total = stats.summary.totalViews;

  return stats.topCountries.map(country => ({
    country: country.country,
    views: country.views,
    percentage: ((country.views / total) * 100).toFixed(1)
  }));
}
```

```tsx
import { useEffect, useState } from 'react';
```

## Caching

Consider caching stats responses to reduce API calls:

```typescript
const cache = new Map<string, { data: any; timestamp: number }>();
const CACHE_DURATION = 5 * 60 * 1000; // 5 minutes

async function getCachedStats(days: number = 30) {
  const cacheKey = `stats_${days}`;
  const cached = cache.get(cacheKey);

  if (cached && Date.now() - cached.timestamp < CACHE_DURATION) {
    return cached.data;
  }

  const response = await fetch(
    `https://api.simplist.blog/v1/analytics/stats?days=${days}`,
    { headers: { 'X-API-Key': apiKey } }
  );

  const data = await response.json();
  cache.set(cacheKey, { data, timestamp: Date.now() });

  return data;
}
```
