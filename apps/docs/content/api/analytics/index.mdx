# Analytics API

The Analytics API provides privacy-first analytics tracking for your blog articles. Track page views, user engagement, and traffic sources while respecting user privacy.

<Callout type="info">
Analytics data is collected with **privacy by default**: IP addresses are hashed, and visitor IDs are anonymized to prevent user tracking across sites.
</Callout>

## Key Features

### Privacy-First

- **No IP storage**: IP addresses are never stored, only used temporarily for deduplication
- **Hashed visitor IDs**: Visitor identification uses cryptographic hashing
- **Bot detection**: Automated traffic is filtered out
- **No cross-site tracking**: Visitor IDs are project-specific

### Rich Data Collection

Track comprehensive engagement metrics:

- **Page views** with unique visitor counting
- **Time on page** for engagement analysis
- **Scroll depth** to measure content consumption
- **Traffic sources** including referrers and UTM parameters
- **Geographic data** (country, region, city)
- **Device information** (desktop, mobile, tablet)
- **Custom events** for interaction tracking

### Request Source Tracking

Distinguish between:
- **SDK requests**: Traffic from [@simplist.blog/sdk](/sdk)
- **Direct requests**: Traffic from your custom implementation

## Bot Detection

The API automatically detects and blocks analytics from:

- Search engine crawlers (Googlebot, Bingbot, etc.)
- Social media bots (Facebookbot, Twitterbot, etc.)
- Developer tools (curl, wget, Postman, etc.)
- Monitoring services (UptimeRobot, Pingdom, etc.)

<Callout type="warn">
Requests from detected bots will receive a `400 Bad Request` error and won't be tracked.
</Callout>

## Analytics Flow

### 1. Initial Page View

When a user lands on an article:

```typescript
const response = await fetch('https://api.simplist.blog/v1/analytics/track', {
  method: 'POST',
  headers: {
    'X-API-Key': 'your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    articleSlug: 'my-article',
    sessionId: 'session_123',
    visitorId: 'visitor_abc',
    pageUrl: 'https://myblog.com/articles/my-article',
    referrer: 'https://google.com',
    screenWidth: 1920,
    screenHeight: 1080
  })
});

const { pageViewId, visitorId, sessionId } = await response.json();
// Store pageViewId for later update
```

### 2. Track Engagement

As the user interacts:

```typescript
// Track scroll events
await fetch('https://api.simplist.blog/v1/analytics/track', {
  method: 'POST',
  headers: {
    'X-API-Key': 'your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    articleSlug: 'my-article',
    sessionId,
    visitorId,
    pageUrl: 'https://myblog.com/articles/my-article',
    events: [
      {
        type: 'scroll',
        position: 50,
        timeOffset: 30000 // 30 seconds
      }
    ]
  })
});
```

### 3. Final Update

When the user leaves:

```typescript
await fetch(`https://api.simplist.blog/v1/analytics/track/${pageViewId}`, {
  method: 'PUT',
  headers: {
    'X-API-Key': 'your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    timeOnPage: 180, // 3 minutes
    scrollDepth: 75,  // 75% of page
    bounced: false
  })
});
```

## Visitor Deduplication

The API automatically deduplicates visitors using:

1. **Client-provided visitor ID** (most reliable)
2. **IP-based deduplication** within 24 hours
3. **Fallback generation** from IP + User Agent hash

<Callout type="info">
Generate a visitor ID client-side and persist it in localStorage for accurate unique visitor tracking across sessions.
</Callout>

## Common Use Cases

### Simple Page View Tracking

```typescript
// On article page load
await fetch('https://api.simplist.blog/v1/analytics/track', {
  method: 'POST',
  headers: {
    'X-API-Key': 'your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    articleSlug: 'getting-started',
    pageUrl: window.location.href,
    referrer: document.referrer
  })
});
```

### Track with UTM Parameters

```typescript
const params = new URLSearchParams(window.location.search);

await fetch('https://api.simplist.blog/v1/analytics/track', {
  method: 'POST',
  headers: {
    'X-API-Key': 'your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    articleSlug: 'campaign-article',
    pageUrl: window.location.href,
    utmSource: params.get('utm_source'),
    utmMedium: params.get('utm_medium'),
    utmCampaign: params.get('utm_campaign')
  })
});
```

### Retrieve Analytics Dashboard

```typescript
const response = await fetch(
  'https://api.simplist.blog/v1/analytics/stats?days=30',
  { headers: { 'X-API-Key': 'your_api_key' } }
);

const stats = await response.json();
console.log(`Total views: ${stats.summary.totalViews}`);
console.log(`Unique visitors: ${stats.summary.uniqueVisitors}`);
```

## Using the SDK

The [@simplist.blog/sdk](/sdk) handles analytics automatically:

```typescript
import { SimplistClient } from '@simplist.blog/sdk';

const client = new SimplistClient({
  apiKey: 'your_api_key'
});

// Track page view
const result = await client.analytics.track({
  articleSlug: 'my-article',
  sessionId: 'session_123',
  pageUrl: window.location.href
});

// Update with final metrics
await client.analytics.update(result.pageViewId, {
  timeOnPage: 180,
  scrollDepth: 75
});
```
