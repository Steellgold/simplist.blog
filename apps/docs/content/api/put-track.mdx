# /v1/analytics/track/:id

Update an existing page view tracking entry with engagement metrics. Use this to send periodic updates or final metrics when the user leaves.

## Endpoint

<ApiPath
  method="PUT"
  path="/v1/analytics/track/:id"
  baseUrl="https://api.simplist.blog"
  testable={true}
  requiresAuth={true}
  parameters={[
    {
      name: "id",
      type: "string",
      required: true,
      description: "Page view ID from initial track response",
    },
  ]}
/>

## Usage Pattern

1. **Initialize tracking** with <InlineRouteLink method="POST" path="/v1/analytics/track" href="/api/post-track" />
2. **Store the returned ID**
3. **Update periodically** (every 30s) with current metrics
4. **Send final update** when user leaves page

<CodeBlock
  tabs={[
    {
      label: "1. Initialize",
      language: "javascript",
      filename: "step-1-initialize.js",
      code: `const response = await fetch('https://api.simplist.blog/v1/analytics/track', {
    method: 'POST',
    headers: {
      'X-API-Key': 'YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ slug: 'my-article', timeOnPage: 0 })
  })

  const { id } = await response.json()`,
    },
    {
      label: "2. Update Periodically",
      language: "javascript",
      filename: "step-2-update.js",
      code: `setInterval(async () => {
    await fetch(\`https://api.simplist.blog/v1/analytics/track/\${id}\`, {
      method: 'PUT',
      headers: {
        'X-API-Key': 'YOUR_API_KEY',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        timeOnPage: getTimeOnPage(),
        scrollDepth: getScrollDepth()
      })
    })
  }, 30000)`,
    },
    {
      label: "3. Final Update",
      language: "javascript",
      filename: "step-3-final.js",
      code: `window.addEventListener('beforeunload', async () => {
    await fetch(\`https://api.simplist.blog/v1/analytics/track/\${id}\`, {
      method: 'PUT',
      headers: {
        'X-API-Key': 'YOUR_API_KEY',
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        timeOnPage: getTimeOnPage(),
        scrollDepth: getScrollDepth(),
        exitPosition: getScrollDepth(),
        bounced: getTimeOnPage() < 5
      })
    })
  })`,
    },
  ]}
/>
